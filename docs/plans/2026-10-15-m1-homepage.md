# M1 首页旗舰页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭起 hmdp-web 的工程骨架、零彩色设计系统与动效基础设施，产出可看的首页旗舰页 demo。

**Architecture:** Vue3 + Vite + TS 单页应用。Lenis 提供全局惯性滚动并与 GSAP ScrollTrigger 同步到同一个 ticker；motion 负责组件级声明式转场与共享元素；GSAP 负责滚动叙事时间轴。暗色区与亮色区通过两套 layout 切换设计 token 作用域。

**Tech Stack:** Vite / Vue 3 / TypeScript / Pinia / Vue Router / Tailwind CSS / shadcn-vue / motion / GSAP + ScrollTrigger / Lenis / axios

**设计文档:** `docs/specs/2026-10-15-二手车平台-design.md`

## Task 4: Lenis ↔ GSAP 同步（最关键的一步）

**Files:**
- Create: `src/lib/gsap.ts`, `src/lib/lenis.ts`

**这一步做错，全站滚动动画都会抖。** 必须严格按下面写。

- [ ] **Step 1: GSAP 注册与全局默认**

`src/lib/gsap.ts`：

```ts
import gsap from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'

gsap.registerPlugin(ScrollTrigger)

gsap.defaults({ ease: 'expo.out', duration: 0.64 })

export { gsap, ScrollTrigger }
```

- [ ] **Step 2: Lenis 单例 + ticker 同步**

`src/lib/lenis.ts`：

```ts
import Lenis from 'lenis'
import { gsap, ScrollTrigger } from './gsap'

let lenis: Lenis | null = null

export function initSmoothScroll(): Lenis {
  if (lenis) return lenis

  lenis = new Lenis({
    duration: 1.1,
    easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
  })

  // 1) Lenis 每帧滚动 → 通知 ScrollTrigger 更新
  lenis.on('scroll', ScrollTrigger.update)

  // 2) 让 GSAP 的 ticker 驱动 Lenis，而不是各跑各的 requestAnimationFrame
  gsap.ticker.add((time) => lenis!.raf(time * 1000))

  // 3) 必须关闭滞后平滑，否则 Lenis 与 GSAP 时间轴不同步，滚动动画会抖
  gsap.ticker.lagSmoothing(0)

  return lenis
}

export function getLenis(): Lenis | null {
  return lenis
}

export function destroySmoothScroll(): void {
  lenis?.destroy()
  lenis = null
}
```

- [ ] **Step 3: 在 App.vue 挂载**

```vue

```

- [ ] **Step 3: 实现**

`src/composables/useCountUp.ts`：

```ts
export type CountKind = 'price' | 'mileage' | 'plain'

export function formatCount(value: number, kind: CountKind): string {
  const raw = kind === 'price' ? value / 10000 : kind === 'mileage' ? value / 10000 : value
  const fixed = raw.toFixed(1)
  return fixed.endsWith('.0') ? fixed.slice(0, -2) : fixed
}
```

再加滚动驱动的 composable 本体（用 GSAP 补间 `ref` 数值，`prefers-reduced-motion` 时直接落到终值）：

```ts
import { ref, onUnmounted, type Ref } from 'vue'
import { gsap } from '@/lib/gsap'
import { useReducedMotion } from './useReducedMotion'

export function useCountUp(target: number, kind: CountKind = 'plain'): {
  display: Ref<string>
  play: () => void
} {
  const reduced = useReducedMotion()
  const display = ref(formatCount(reduced.value ? target : 0, kind))
  const state = { v: reduced.value ? target : 0 }
  let tween: gsap.core.Tween | null = null

  const play = () => {
    tween?.kill()
    tween = gsap.to(state, {
      v: target, duration: 1.2, ease: 'expo.out',
      onUpdate: () => { display.value = formatCount(state.v, kind) },
    })
  }
  onUnmounted(() => tween?.kill())
  return { display, play }
}
```

- [ ] **Step 1: axios 实例**

`src/api/client.ts` —— **header 名必须是小写 `authorization`**（后端 `LoginInterceptor` 读的就是这个 key）：

```ts
import axios from 'axios'

export const http = axios.create({ baseURL: '/api', timeout: 10000 })

http.interceptors.request.use((config) => {
  const token = localStorage.getItem('hmdp_token')
  if (token) config.headers.set('authorization', token)
  return config
})

http.interceptors.response.use(
  (res) => {
    const body = res.data
    // 后端统一响应体：{ success, errorMsg, data, total }
    if (body && body.success === false) {
      if (body.errorMsg === '请登录') {
        localStorage.removeItem('hmdp_token')
        window.location.href = '/login'
      }
      return Promise.reject(new Error(body.errorMsg || '请求失败'))
    }
    return body
  },
  (err) => Promise.reject(err),
)
```
